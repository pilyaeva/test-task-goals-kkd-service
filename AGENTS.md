# Project: test-task-goals-kkd-service

Производит контроль качества данных для целей и ключевых результатов.

Подробности для людей - в README.md.

## Stack:
- Java 21
- Spring Boot 3.5.6
- Spring Web
- Spring Data JPA
- PostgreSQL 18
- Flyway
- Maven
- JUnit 5

## Setup commands

```bash
# первая установка
cp .env.example .env  # потом заполнить вручную, см. список ниже

# запуск

```

## Команды

- Сборка: `./mvnw clean verify`
- Тесты: `./mvnw test`
- Запуск локально: `./mvnw spring-boot:run`

## Главные правила

1. Перед изменением кода читай `specs/`.
2. Если меняешь публичный API, сначала обнови `specs/design.md`.
3. Не добавляй новые зависимости без обсуждения.
4. Контроллеры не содержат бизнес-логику.
5. Сервисы содержат бизнес-правила.
6. Контроллеры к сервисам обращаются через интерфейсы.
7. Репозитории только работают с данными.
8. Для запросов и ответов использовать record DTO.
9. Entity-классы не должны попадать в API-слой.
10. Все новые фичи должны иметь тесты.
11. Ошибки возвращать в едином формате из `specs/design.md`.

## Структура пакетов

- `com.example.testtask.api` — контроллеры, DTO, ошибки
- `com.example.testtask.application` — сервисы
- `com.example.testtask.domain` — сущности и бизнес-правила
- `com.example.testtask.infrastructure` — репозитории, конфигурация

## Определение готовности

Задача готова, если:

- код компилируется;
- тесты проходят;
- обновлены спеки, если менялось поведение;
- нет новых предупреждений компилятора без причины;
- добавлены тесты на основные негативные сценарии.
