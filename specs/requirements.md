# Requirements

## Цель проекта

Сервис для расчёта и визуализации процедуры контроля качества данных (далее - ККД). В нём администраторы системы, руководители департаментов и ответственные за целеполагание в бизнесподразделениях на периодической основе (планируется еженедельно) проверяют качество данных по целям и ключевым результатам.

## Функциональные требования

### R-001. Получение списка прогонов

Пользователь может получить список прогонов: статус, дата снимка, с каким прогоном сравнивается, число найденных проблем.

Критерии приёмки:

1. [ ] Сервис отдаёт список прогонов с полями в ответе: статус, дата снимка, с каким прогоном сравнивается, число найденных проблем.
2. [ ] Если прошлого прогона нет, то дельта равна null.

### R-002. Получение метрик по целям и ключевым результатам
